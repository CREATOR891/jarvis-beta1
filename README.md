# 🤖 JARVIS Beta — голосовой ассистент для Android

Голосовой помощник в стиле Джарвиса: управление телефоном голосом, озвучка ответов, живые персонажи и эффекты поверх экрана.

## ✨ Возможности

- 🎤 **Голосовые команды** — распознавание речи (SpeechRecognizer, русский язык)
- 🔊 **Озвучка ответов** — TextToSpeech, несколько голосов (2 бесплатных + 2 под Premium)
- 📱 **Управление телефоном** (Accessibility Service):
  - «Открой Телеграм / WhatsApp / YouTube / Настройки…»
  - «Домой» — возврат на главный экран, «Недавние» — список приложений
  - «Принять звонок» / «Сбросить»
  - «Шторка» — быстрые настройки (Wi-Fi, Bluetooth)
- ❄ **Снег поверх экрана** — включается голосом («Снег») или переключателем
- 🐾 **Персонажи-помощники** поверх экрана: Робот Джарвис, Призрак (бесплатно) + Кот Оксид, Рыба Неон (Premium)
- 🌑 **Интерфейс** — тёмная тема «чёрно-золото + неон», кнопка микрофона, выбор голоса и персонажа, кнопка «Сообщить об ошибке»

## 🚀 Сборка APK через GitHub Actions

1. Форкните или склонируйте репозиторий
2. Перейдите во вкладку **Actions** — сборка запустится автоматически (workflow `build.yml`)
3. После зелёной галочки скачайте артефакт `jarvis-beta-apk` → внутри `app-debug.apk`

Или соберите локально: откройте папку в Android Studio → **Build → Build APK(s)**.

## ⚙️ После установки

1. Разрешите микрофон и «отображение поверх других приложений»
2. Включите **Службу доступности** (кнопка в приложении)
3. Premium (Beta) активируется кодом: `JARVIS-BETA-2026`

## 🗣️ Примеры команд

> «Открой Телеграм» · «Домой» · «Недавние» · «Шторка» · «Принять звонок» · «Сбросить» · «Снег»

## ⚠️ Beta-ограничения

- Приём/сброс звонков зависит от приложения-звонилки
- Распознавание речи требует интернет (Google Speech)
- Набор голосов зависит от TTS-движков устройства
